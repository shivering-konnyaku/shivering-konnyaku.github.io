## Updating the homepage

Edit `index.html` and commit to the `main` branch. GitHub Pages publishes the files in the repository root. There are no dependencies or build steps. The `.nojekyll` file keeps the site as plain static HTML.

The page includes English and Chinese text. Update the default visible text and the corresponding `data-en` and `data-zh` attributes together.
